This repository contains a comprehensive computational implementation of the Household Transmission Epidemic Model using Master Equations to capture the granular dynamics of infectious disease spread. Unlike standard Susceptible-Infectious-Recovered models that assume completely homogeneous mixing across an entire population, this specialized model introduces a two-layered transmission mechanism that explicitly distinguishes between interactions taking place within the same household and interactions occurring across the broader community. The system models the temporal evolution of probabilities for various epidemiological states defined as four-tuples representing the number of susceptible, infectious, and recovered individuals within a household of a specific size. This material serves as a structured educational lab tutorial that guides users through background mathematics, detailed problem scenarios, step-by-step programming modules, and complex data visualization techniques using Python.

The underlying theoretical framework expands traditional compartment models by introducing separate transmission rates where the inter-household or community infection rate depends heavily on the overall global prevalence of infectious individuals while the intra-household infection rate relies strictly on the micro-concentration of infected individuals within that specific home. The system of master equations establishes precise differential relations for individual households where the rate of change for susceptible individuals is driven by both community exposure and immediate family exposure. For the full population, the model aggregates individual household contributions across the entire community by summing the discrete states to compute total societal dynamics, maintaining exact balance relations where the total population remains invariant throughout the timeline of the outbreak.

The concrete problem scenario simulated within the notebook defines a population of thirty individuals distributed unevenly across twenty households, split evenly between ten single-person households and ten two-person households. The initial epidemiological state at time zero introduces a single infectious individual inside one of the two-person households while all other individuals across the community remain fully susceptible. The theoretical analysis explores the transmission cascade under a community constant of three, a household constant of two tenths, and a recovery coefficient of three tenths, calculating how the epidemic propagates through different household structures over time to evaluate the expected number of active infections, the expected daily new cases, and the expected cumulative attack rates across different strata.

The Python programmatic implementation is divided into several clear linear execution phases without relying on traditional structural listings, moving naturally from initial environment setup to final analysis. First, the script imports necessary scientific computing packages including NumPy, Pandas, and Matplotlib alongside collection utilities to initialize global population parameters and configure the initial probability vectors across all possible mathematical combinations. Next, the tutorial defines core auxiliary functions to evaluate global quantities at each discrete step and compute structural transition rates based on specific infection or recovery events. A pivotal updating function utilizes a meticulous backtracking methodology to scan all possible previous structural states that could transition into the current state via an infection or a recovery event, advancing the entire probability distribution forward by an explicit numerical step.

Following the probability advancement framework, the implementation integrates index tracking mechanisms to extract expected physical statistics from the changing probability densities over time. Dedicated routines compute the total expected susceptible, infected, and recovered individuals for each separate household size group, while consecutive differences allow the calculation of expected daily incident cases. The final stages focus on comprehensive graphical visualization where the script prepares multi-panel coordinate plots using Matplotlib to demonstrate the structural differences in the epidemiological curves. These plots illustrate the distinct peak heights and velocities of the epidemic between single-person and two-person homes, chart the daily incidence rates, map the cumulative attack rates relative to the population at risk, and trace the smooth continuous shift of individual state probabilities across the simulation timeline.

To run this model locally, you must have a functional Python installation equipped with data science packages including NumPy, Matplotlib, Pandas, and OpenPyXL for data management. Users can download the repository files, open the terminal in the workspace directory, and execute the command to launch Jupyter Notebook where the full document can be evaluated sequentially. The notebook comes with built-in export modules that write the precise mathematical distributions directly to an Excel file format for further validation, making it an excellent resource for researchers and students studying mathematical epidemiology or stochastic modeling.
